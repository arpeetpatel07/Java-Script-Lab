String Operations in JavaScript

Strings are one of the most useful data types in JavaScript. They let us store text, search within text, change content, and perform many operations such as slicing, replacing, splitting, and counting characters.

a) Basics of Strings

  • A string is a sequence of characters enclosed in single or double quotes.
  • It supports operations like length, concatenation, slicing, and searching.
  • Example: "Hello" has a length of 5.
let name = "JavaScript"; console.log(name.length); // 10 console.log(name + " is fun"); console.log(name[0]); // J

b) Working with Strings

Common string methods help us manipulate text quickly and efficiently.

substring()

Extracts a part of a string.

indexOf()

Finds the position of a substring.

split()

Breaks a string into an array using a separator.

replace()

Replaces a matched value with another string.
